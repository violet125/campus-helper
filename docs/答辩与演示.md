- `presentation.html` 封面的姓名、学号。
- 若两人合作，添加真实分工；不要编造提交者独立完成的工作。

## 前 4 分钟：10 页 HTML

1. 20 秒：我是……，项目是校园小帮手，选择路径 A。为学生提供校园办事和自习计划。
2. 25 秒：材料、开放时间和空闲教室分散，学生需要按自己的时间组合信息。本项目用虚构数据验证这个流程。
3. 30 秒：界面到 Agent，再调用模型与工具。强调模型决定调用，业务函数验证时间，MCP 是协议接入。
4. 30 秒：四个自定义工具和四个 MCP 查询。指出 `campus.py` 的 `build_visit_plan()`，并演示 `get_weather_forecast()` 查询 Open-Meteo。
5. 25 秒：Skill 指导工作顺序，researcher 核查，critic 审核，最后写文件。
6. 20 秒：双数据库保证重启后仍可追问。流式事件展示调用证据。
7. 25 秒：对课堂的增量包括真实可执行的排程规则、校园数据、失败解释、技能和权限隔离。
8. 20 秒：数据虚构，不采集真实身份，无真实提交，不把样例当成官方制度。
9. 25 秒：主路径现场演示顺序，展示查询、计划、下载与周末失败场景。
10. 20 秒：尚无真实校园 API、身份认证与节假日数据，在线模型仍需配置和现场试跑。

## 后 4 分钟：现场操作

提前启动网页，确认网络、Key 和模型可用。主任务可能耗时几分钟，正式汇报前应完整试跑。

1. 0:00–0:35 查询“校园卡补办需要什么材料？请查样例指南”。展开执行过程，指认 `search_services`。
2. 0:35–2:35 提交“请规划 2026-10-27 13:30 到 17:30 的行程：先补校园卡，再还书，最后自习 60 分钟。请核查并生成 Markdown 文件”。展示待办、子代理、`build_visit_plan` 和 `write_file`。
3. 2:35–3:05 切到“产出文件”，预览并下载。核对每段时间、步行间隔、数据来源。
4. 3:05–3:35 追问“改成 2026-11-01 呢？”检查是否明确校园卡窗口关闭。
5. 3:35–4:00 打开代码，指认 `campus.py` 的时间冲突判断、`mcp_server.py` 的工具注册、`agent.py` 的框架组装与权限。

如果模型响应较慢，可以提前保留一次真实跑通的历史会话和文件，在现场解释已有结果，同时启动一条较快的真实查询。不要将脚本测试模型或规则页称为大模型现场演示。教师允许的录屏备用应不超过 3 分钟，由提交者实际操作录制。

## 常见问答

**为什么不是普通聊天框？**
模型在 LangGraph 图中多轮调用工具，按 Skill 规划、核查并写文件，检查点保存完整上下文。时间表由工具算出。

**不用工具会怎样？**
模型不知道样例窗口的开放时间和教室占用，容易给出错误时段。工具提供结构化事实与确定性校验。

**Skill 与系统提示词有什么区别？**
系统提示词是全局角色和边界；Skill 是具体任务的按需操作手册，能附带模板。框架启动先看到技能描述，需要时再读全文。

**MCP 与普通函数有什么区别？**
普通工具在本进程内调用；MCP 提供跨进程的标准工具发现和调用协议。本项目用 stdio 启动 Python 服务器，并通过适配器转成 LangChain 工具。

**为什么有两个数据库？**
checkpoints 保存模型可继续执行的图状态，sessions 保存 UI 标题、用户可见消息和调用记录。两者靠 thread_id 关联。

**为什么不让模型自己排时间？**
模型负责理解意图和填写参数。业务函数负责完整时段、开放窗口、重叠和步行间隔校验，结果更可测试。

**无障碍筛选保证什么？**
只保证样例自习空间标记符合条件，窗口和真实路线可达性没有数据，必须另行核实。

**权限怎么做？**
不挂载项目根目录，只暴露公开上下文和工作目录，框架写权限只允许 `/workspace/**`。它不是操作系统级沙箱。

**你自己的工作是什么？**
如实说明使用课堂设计与 AI 辅助。重点解释自己实际理解、修改和验证的业务场景、规则、测试、演示步骤，不能把生成代码说成未经辅助独立手写。

## 交付前核对

- 填写封面姓名学号，核实分组及汇报日期。
- 使用自己的 Key 跑通真实查询、计划与导出，保留可核验的执行记录。
- 双击 HTML 能打开，测试教室显示尺寸和翻页。
- 上传 Git 仓库，确认 `.env`、数据库、虚拟环境未进入暂存区。
- 运行 `python -m unittest discover -s tests -v`。
- 按教师指定渠道提交仓库链接及 HTML；本项目未代为发布。
