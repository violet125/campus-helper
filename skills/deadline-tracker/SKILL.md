# 作业与事项截止日期提醒

1. 对“今天、明天、下周五”等相对日期，先调用 `get_current_time`，按其 Asia/Shanghai 日期换算为明确的 `YYYY-MM-DD`。如果“周五”等表述可能指本周或下周且上下文不能确定，先询问，不要猜测。
2. 用户询问还剩几天时，调用 `calculate_days_until`，并直接依据 `days_remaining` 作答：今天为 0，过去日期为负数并明确说明已逾期。
3. 只有用户明确要求记下、保存或提醒某项截止日期时，才调用 `save_deadline`。将事项名称和明确日期传入工具；不得声称设置了系统通知、闹钟或外部提醒。
4. 保存工具成功后，告知其写入 `/workspace/deadlines.md`。保存失败时如实报告，不要说已记录。
5. 用户询问“还有什么作业/我记了什么”时，读取 `/workspace/deadlines.md` 并按文件内容回答。文件不存在时说明当前没有已保存的截止事项；不能凭空补充。若询问已保存事项还剩几天，必须对文件中的截止日期重新调用 `calculate_days_until`，不能使用保存时的倒数。
6. 校验日期和工具结果；不采集姓名、学号、手机号等个人信息，不把截止日期数据发送到外部系统。
