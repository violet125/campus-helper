# 天气查询与出行提示

1. 确认要查询的城市或地区。校园小帮手没有真实学校地址或 GPS；用户只说“学校/校园”或“明天会下雨吗”但没有提供位置时，直接询问所在城市/区县，不要声称天气查询功能不可用，也不要猜地点。
2. 确认查询日期。对于今天、明天、周末等相对日期，先调用 `get_current_time` 获取 Asia/Shanghai 日期，再换算成 `YYYY-MM-DD`。没有日期语境时先询问用户想查哪天。
3. 调用 MCP 工具 `get_weather_forecast(location, day)`。地点有多个候选时，列出候选并请用户选择，不要采用任意一个。
4. 只依据工具返回的天气、温度、降水概率和降水量作答。说明城市级预报不等于校园微气候或官方预警。
5. 仅在工具返回 `umbrella_recommended` 为 true 时建议带伞；数据缺失、超出预报范围或网络失败时明确说明无法确认，不猜天气。
6. 地点名称会发送至 Open-Meteo 地理编码服务以获取坐标，并向其天气预报服务请求公开天气数据。不要发送用户身份信息或其他无关内容。
